# 作者声纹与质量门禁

## 目标

把“去 AI 味”改写为“建立作者味”。不要为了伪装来源而故意加入错误、口语毛刺或随机不完美。诊断文本中的模式，确认作者意图，再做局部修改。

## 常见机械感

按上下文判断，不因单次出现直接判错：

1. 所有句子和段落长度相近，节奏没有局部变化。
2. 每段最后一句都总结、升华或替读者解释意义。
3. 动作已经表达情绪，旁白又说明一遍，心理再确认一遍。
4. “仿佛、犹如、宛如”连续承担画面感，意象彼此无关。
5. “瞳孔骤缩、呼吸一滞、空气凝固、心头一震”成为通用反应。
6. 场景总以天气、光线或全景开始，再机械推进人物。
7. “就在这时、与此同时、下一秒、然而”固定出现在转折处。
8. 每个角色都表达完整、逻辑严密、句式相似，没有口误、回避或个人词汇。
9. 人物在冲突后迅速说清全部感受，情绪曲线过于圆满。
10. 伏笔被旁白标亮，秘密出现时立刻提示“事情并不简单”。
11. 结尾固定使用突发声响、陌生人、震惊台词或“一切才刚刚开始”。
12. 把一个动作拆成大量无效步骤，或同时调用五种感官填充篇幅。
13. 使用精确但没有观察来源的时间、角度、距离和身体数据。
14. 频繁用“不是 X，而是 Y”制造伪深刻。
15. 反复替人物和读者概括“真正的意义”“命运”“时代”。

## 不要误伤

- 悬疑、恐怖中的重复可以制造强迫感。
- 战斗中的短句密集可能是刻意加速。
- 诗性文本需要意象与复沓。
- 网文断章需要余压，但不等于每章都要惊天反转。
- 角色口头禅可以重复，但其他角色不应共享。

保留有明确叙事功能的模式。诊断报告只能说“疑似机械模式”，不能宣称文本由 AI 生成。

## 作者声纹文件

`style/author-voice.md` 至少记录：

- 声音关键词：3–6 个。
- 叙述距离与视角纪律。
- 句长、段长的变化范围。
- 对白习惯与沉默方式。
- 描写优先级。
- 允许重复的核心意象。
- 禁用表达和不喜欢的套路。
- 刻意保留的不规则之处。
- 每个主要角色的说话差异。

如果作者没有样文，先创建暂定声纹，并在每 3–5 个定稿章后根据作者实际修改记录迭代。只从作者批准的修改学习，不从未经确认的草稿学习。

## 正文生成检查

写每个场景前在内部回答：

1. 视角人物此刻要什么？
2. 他不愿承认什么？
3. 谁或什么施加阻力？
4. 他尝试了什么策略？
5. 哪个细节只有这个人物会注意？
6. 场景结束时什么发生了不可逆变化？

正文中不要输出这些答案。若场景没有变化，删去、合并或重新定义其功能。

## 事实审稿格式

只报告可举证的问题：

```json
{
  "items": [
    {
      "category": "角色知情范围",
      "severity": "error",
      "quote": "问题原句",
      "canonEvidence": "与之冲突的定稿事实及章节",
      "description": "为什么构成矛盾",
      "minimalFix": "不改变本章目的的最小修改方向"
    }
  ],
  "summary": "总体结论"
}
```

`severity` 使用 `error`、`warning`、`pass`。没有证据时不报错；不要为了填满类别而制造问题。

## 作者化审稿格式

按正文顺序引用命中段落，说明：观察到的模式、它可能伤害什么、是否可能是作者刻意选择。不要直接整段重写。作者确认需要修改后，保持原意和声纹做最小调整。

重点检查：

- 这一段是否解释了读者已经看见的东西？
- 这句话是否只有当前作者或角色会这样说？
- 比喻是否来自人物经验，而非通用素材库？
- 对白是否带着目的和回避？
- 节奏变化是否来自场景压力？
- 结尾是否自然产生余压，而非套用钩子模板？

## 修稿顺序

1. 修正正史矛盾和因果断裂。
2. 修正视角越界和角色声纹混同。
3. 删除重复解释和无功能段落。
4. 替换套话时回到人物感知，不做同义词轮换。
5. 调整节奏，只改变确有问题的段落。
6. 复查修稿是否引入新的事实、能力或情节。

不要以“文笔升级”为名增加大量形容词、五感、哲理或篇幅。

## 题材门禁

- 玄幻/仙侠：能力是否有边界和代价；胜负是否由已知条件产生。
- 科幻：核心假设是否自洽；新技术是否提前建立；术语是否可理解。
- 爱情：关系推进是否来自选择；边界与承诺是否连续；误会是否可被简单一句话消除。
- 悬疑：关键线索是否公平出现；证据链是否成立；角色是否因作者需要而降智。
- 历史：年代、称谓、制度、交通和物质条件是否可靠。
- 恐怖：规则是否逐步被验证；未知是否仍保留；危险是否依赖角色愚蠢。
- 都市/现实：职业、钱、时间和社会后果是否可信。

## 使用诊断脚本

运行：

```bash
python3 scripts/check_prose.py path/to/chapter.md
python3 scripts/check_prose.py path/to/chapter.md --json
```

脚本只筛查可机械检测的表层模式。必须结合本文件的人工门禁，尤其检查角色声音、因果、视角和情绪真实性。
