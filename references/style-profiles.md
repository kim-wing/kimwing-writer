# 文笔与叙事预设

文笔控制语言质地，题材控制故事承诺。不要让文笔预设覆盖人物动机、世界规则或情节事实。

## 文笔 ID

### `fast-web` 快节奏连载

- 短段落，动作与对白优先，信息快速兑现。
- 保留必要铺垫，不强迫每段制造金句或每章反转。
- 避免旁白重复解释爽点和人物情绪。

### `restrained` 冷静克制

- 用具体行为和物件承载情绪，少用评价性形容词。
- 句子干净，允许沉默和未说完的话。
- 避免把克制写成人人冷漠或故意省略关键信息。

### `delicate` 细腻情感

- 放大微小选择、身体距离、语气变化和记忆触发。
- 心理描写必须改变角色下一步行动。
- 避免同一情绪被心理、动作、比喻和旁白反复说明。

### `classical` 古典雅致

- 采用自然的古典词汇、意象和节奏，不机械仿文言。
- 意象必须与人物处境或场景变化有关。
- 避免四字词堆叠、生僻字炫技和现代网络句式换古词。

### `cinematic` 电影镜头感

- 通过视线、空间、动作连续性和声音组织场面。
- 镜头选择服务于角色注意力，不使用无主的摄影机视角。
- 避免每场都从全景推到特写，以及滥用慢动作身体反应。

### `hard-edged` 冷硬锋利

- 动词准确，句子有切口，对话保留威胁和信息差。
- 暴力或危险强调后果，不以形容词替代力度。
- 避免全员说金句、持续高压导致失去层次。

### `humorous` 轻松幽默

- 幽默来自人物目标、误读、节奏落差和具体观察。
- 让不同角色拥有不同笑点和尴尬反应。
- 避免网络梗堆积、旁白替读者笑和每段强行抖包袱。

### `lyrical` 诗性抒情

- 允许长句、意象复现和感官联想，但保留叙事方向。
- 建立少量核心意象，让它们随人物变化获得新含义。
- 避免随机比喻、泛化哲理和无对象的“命运”“时间”“灵魂”。

### `documentary` 纪实写实

- 使用职业、物件、程序和生活成本构成可信细节。
- 不美化痛苦，不替人物做道德总结。
- 避免资料罗列和为了显得真实而加入无关数字。

### `ensemble` 群像叙事

- 每条人物线拥有独立欲望、代价和语言节奏。
- 转换视角时带来新信息或新的误读。
- 避免平均分配篇幅、角色轮流完成同一种功能。

## 叙事视角 ID

- `first-person`：只能写“我”可感知和理解的内容；允许自我欺骗。
- `third-limited`：每个场景绑定一个视角人物；切换时明确分场。
- `third-omniscient`：叙述者可以越过个体，但必须有稳定态度和信息节奏。
- `multi-pov`：为每个视角规定职责、声纹和切换条件。

不要用“全知视角”修补信息组织失败，也不要在第三人称有限视角中偷写他人内心。

## 组合参数

在 `style/author-voice.md` 中把预设转成可执行参数：

```text
基础文笔：restrained + cinematic
句长：短句为主，冲突前允许长句累积
段落：1–4句，不追求均匀
叙述距离：贴近主角感官，不解释他人内心
对白：短，回避直接回答；禁止全员金句
环境：只写会影响行动的细节
心理：每段心理必须导致选择或误判
修辞：每千字不超过2个显性比喻；重复意象优先于新意象
章末：保留未解决压力，不固定使用突发事件
```

数值是项目偏好，不是机械配额。发现遵守数值反而伤害文本时，记录作者决定后调整。

## 从样文建立作者声纹

优先使用作者本人提供的 2000–5000 字样本。分析：

1. 句长和段长的分布，而非只算平均值。
2. 叙述距离、视角边界和信息隐藏方式。
3. 动作、对白、心理、环境的实际比例。
4. 常用动词、重复意象、口语程度和标点习惯。
5. 人物情绪如何变成行动。
6. 作者刻意保留的毛边、跳跃和沉默。
7. 明确禁用的套话和不喜欢的表达。

输出抽象、可执行的声纹，不保存大段原文。用户要求模仿具体作者时，改为描述高层技法并创建新的混合配置，不生成“某作者复制品”。
