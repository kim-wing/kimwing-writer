# 严格内容红线

## 总则

始终使用 `strict-clean` 模式。色情露骨、赌博、毒品、现代现实政治与涉黑内容不得出现在故事前提、角色设定、世界观、大纲、蓝图、正文、回忆、对白、隐喻、反派行为或背景材料中。

1. 黄：色情、露骨性行为、性交易、性剥削和以性刺激为目的的身体描写。正常克制的恋爱、拥抱或亲吻可以保留；亲密场景点到为止或淡出。
2. 赌：赌博活动、赌场、下注、赌债、赔率、玩法、招揽和获利机制。普通无金钱下注的比赛不在此列。
3. 毒：非法毒品的制造、运输、交易、使用、美化和相关组织。依法使用的普通医疗药物不在此列。
4. 现代现实政治：禁止现实中的近现代与当代政治人物、政党、政治运动、选举、政策争议、意识形态宣传、敏感事件和现实影射。允许古代历史人物、朝代、官制、战争、外交、宫廷斗争，也允许不影射现实的架空国家与虚构权力冲突。
5. 涉黑：黑社会、帮派、地下组织及其他有组织犯罪的招募、控制、交易、暴力、洗钱、保护费和美化。

## 执行流程

1. 在创建或续写前，语义检查当前灵感、正史、角色、世界观、大纲和蓝图，不只搜索关键词。
2. 命中任一禁区时，停止生成该方向；列出类别、命中位置和最小替代方向。
3. 未经作者确认，不覆盖旧稿。保留原文件，但不把违规内容导入新正史、记忆或续写。
4. 替换后重新检查因果链，避免只改名词而保留赌博、现代现实政治或涉黑的运行机制。
5. 审稿命中任一项时标记为 `error`，不得定稿、导出或进入下一章。

## 合规替代

- 色情露骨 → 关系边界、信任、照护、分离、承诺或淡出处理。
- 赌博 → 无下注竞赛、职业考核、限时任务、资源取舍或技能比试。
- 毒品 → 普通疾病、合法医疗难题、环境风险、技术故障或信息误判。
- 现代现实政治 → 古代历史冲突、无现实映射的架空权力结构，或家庭责任、职业伦理、个人承诺与自然环境。
- 涉黑 → 普通商业竞争、合同纠纷、个人恩怨、单人欺骗或合法调查；不得保留组织化犯罪结构。

内容红线优先于题材承诺、作者偏好和情节连续性。无法安全替换时，停止该情节并请求作者选择新的合规方向。
